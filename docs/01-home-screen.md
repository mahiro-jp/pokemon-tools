# ホーム画面

## 1. 概要

本画面はアプリへのアクセス時に最初に表示されるポータル画面です。  
ユーザーが目的の機能へスムーズに遷移できるランチャーとして機能します。

---

## 2. 画面レイアウト

```
+-------------------------------------------------------+
|                     ポケモンツール                    |
+-------------------------------------------------------+
|                                                       |
|   ツールを選択してください。                          |
|                                                       |
|   +-------------------+  +-------------------+        |
|   |  ポケモン登録     |  |  パーティ作成     |        |
|   +-------------------+  +-------------------+        |
|                                                       |
|   +-------------------+                               |
|   |  ダメージ計算     |                               |
|   +-------------------+                               |
|                                                       |
+-------------------------------------------------------+
|                                     [ ダークモード ]  |
+-------------------------------------------------------+

```

---

## 3. 主要UIコンポーネント一覧

| 要素名 | 種別 | 表示内容 | アクション |
| --- | --- | --- | --- |
| **ヘッダー** | 固定バー | "ポケモンツール" | なし |
| **ポケモン登録カード** | リンクボタン | "ポケモン登録" | `/pokemons` |
| **パーティ作成カード** | リンクボタン | "パーティ作成" | `/parties` |
| **ダメージ計算カード** | リンクボタン | "ダメージ計算" | `/damage-calculator` |
| **フッター** | 情報エリア | "ダークモード"/"ライトモード" | ダークモード切替 |

---

## 4. 各機能カードの表示要件

- **ポケモン登録 (`/pokemons`)**
  - アイコン: プラスアイコン
- **パーティ作成 (`/parties`)**
  - アイコン: リストアイコン
- **ダメージ計算 (`/damage-calculator`)**
  - アイコン: 計算機アイコン

---

## 5. 非機能・デザイン要件

- **レスポンシブ対応:**
  - PCでは2列のグリッド配置、スマートフォン表示時は縦1列へ自動可変
- **タッチ最適化:**
  - スマートフォンでの誤タップを防ぐため、各カードの最小高さを 80px 以上、タップ可能エリアを十分確保
- **テーマ対応:**
  - ダークモードに対応、ダークモードボタンのクリックでオン/オフを切り替え
