# ポケモンツール: ホーム画面

共通の色・文字・余白・コンポーネントのルールは[スタイルガイド](./00-style-guide.md)を参照する。

## 1. アプリの概要と全体構成
- ゲームのポケモンチャンピオンズをサポートするツール。
- 複数のツールを1つにまとめたWebアプリ。
- **画面構成:** 画面上部に「共通ヘッダー」、中央に「メインコンテンツエリア」、下部に「共通フッター」を配置する。
- **画面遷移の仕組み（SPA方式）:**
  - `index.html` の1ファイル内で、JavaScriptを使って「メインコンテンツエリア」の表示要素（セクション）を切り替えることでページ遷移を表現する。
  - ページを再読み込みしても現在の画面が維持されるよう、URLハッシュ（例: `#home`）と連動させること。

## 2. 共通エリアの要件（全画面で常に表示）
- **共通ヘッダー (`<header>`)**
  - 左側：アプリのロゴ・タイトル（クリックすると常に「ホーム画面」へ戻る）
    - ロゴはモンスターボール型、タイトルはポケモンツール
  - 右側：ナビゲーションメニュー（ホーム画面に戻らず各機能に遷移できる）
  - スクロールしても上部に固定（sticky）されるデザインにする。
- **共通フッター (`<footer>`)**
  - 左側：ダークモードの切り替え
  - 右側：保存ボタンや削除ボタンなど各機能ごとにページ全体に影響する機能ボタンを配置する。
  - コンテンツが少ない場合でも、常に画面の一番下に配置されるレイアウト（Sticky Footer）にする。

## 3. ホーム画面（メインエリア初期表示）の要件
- **ウェルカムメッセージ:** 上部に簡単な説明文を表示する。
  - 「カードを選んでください」ということが伝わるようにする。
- **機能リンクカード一覧（CSS Gridレイアウト）:**
  - 各機能へ移動するための「カード型ボタン」をグリッド状に並べる。
  - **レスポンシブ対応:** PC画面では横3列、スマホ画面では横1列に自動調整されること。
  - **各カードに含める要素:**
    1. アイコン（シンプルなSVGアイコン）
    2. 機能タイトル
    3. 機能の簡単な説明文（1〜2行程度）
  - **カードの動作:**
    - マウスを乗せたとき（ホバー時）に、少し浮き上がるようなアニメーションをつける。
    - カード全体をクリック可能にし、クリックすると該当する機能の画面へメインエリアが切り替わる。

## 4. 初期配置する機能カード（ダミー画面の用意）
まずは以下の機能カードをホーム画面に配置し、クリックした先の各画面には「タイトル」と「ホームへ戻るボタン」だけを置いたダミー（枠組み）を用意すること。
1. **ポケモン登録**
   - アイコン：モンスターボール型
   - 説明：ポケモンのステータスや技構成などを登録します。
2. **パーティ作成**
   - アイコン：リスト型
   - 説明：登録したポケモンからパーティを作成します。
3. **ダメージ計算**
   - アイコン：電卓型
   - 説明：技のダメージを計算します。登録したポケモンの読込や計算結果を登録することができます。

## 5. デザイン・UIルール
- 背景は目に優しい薄いグレー、カードやヘッダーは白を基調とし、清潔感のあるモダンなデザインにする。
- ダークモードは濃いグレーを基調とする。
- アクセントカラーとしてモンスターボールをイメージした赤を使う。
- カードには適度な角丸（`border-radius`）と薄い影（`box-shadow`）をつけ、立体感を出す。
